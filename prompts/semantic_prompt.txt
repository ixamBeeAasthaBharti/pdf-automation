IMAGE HANDLING — THREE-PATH DECISION
=====================================================
For EVERY attached image, classify it into exactly ONE of these three paths:

PATH A — IMAGE IS A TABLE
A table means ANY of the following:
- A visible grid with rows and columns of data.
- A two-column or multi-column COMPARISON LAYOUT (e.g. "Companies Act, 2013" vs "SEBI Regulations, 2015").
- Side-by-side coloured boxes presenting structured information under column headings.
- A key-value layout (e.g. "Particulars" | "Details").
- Any content where information is organised in parallel columns, even without visible grid lines.
- Study note snippets that contain a comparison or structured multi-column box.
IMPORTANT: Even if the overall image has decorative headers, logos, or page numbers — if the MAIN CONTENT is tabular/structured in columns, classify it as PATH A.
Action:
- Extract ALL visible content into semantic HTML. Remove the <img> tag.
- See TABLE IMAGES (CRITICAL) section below for exact output format.

PATH B — IMAGE IS TEXT-ONLY
Text-only means the image contains ONLY readable text with no drawings, diagrams, or charts:
- Section headings / subheadings
- Paragraphs of explanation or definitions
- Bullet point lists or numbered lists
- Highlighted or bold key terms followed by explanations
- Study note snippets with ONLY text content (no arrows, no boxes connected by lines, no flowcharts)
Examples: A section like "Appointment of Directors (Section 152)" with bullet points; "Belated Return [Section 139(4)]" with paragraphs.
NOT text-only: any image where the main informational content is a flowchart, diagram, node-and-arrow chart, or visual illustration — even if it also has some text labels.
Action:
- Extract ALL visible text in reading order. Remove the <img> tag.
- Output format:
  <div class="extracted-text-block">
    <h4 class="extracted-heading">Section Title Here</h4>
    <p>Paragraph text...</p>
    <ul><li>Bullet point...</li></ul>
  </div>
- Use <h4 class="extracted-heading"> for section headings.
- Use <p> for paragraphs.
- Use <ul><li> for bullet lists, <ol><li> for numbered lists.
- Use <strong> for bold text, <em> for italics.
- Preserve highlighted/underlined terms using <strong> or <u>.
- Skip decorative elements: watermarks, logos, page numbers, dividing lines.
- Do NOT duplicate text that already exists outside the image in the surrounding HTML.

PATH C — IMAGE IS A VISUAL (diagram, chart, flowchart, photograph, screenshot of UI)
All remaining images fall here:
- Flowcharts (boxes connected by arrows, node-and-arrow diagrams)
- Bar/pie/line charts, graphs
- Photographs, illustrations
- Screenshots of external applications or exam portals
- Images where the main content is a DIAGRAM even if it also has text labels

- For flowcharts/diagrams: wrap in <figure><img src="..."><figcaption>...</figcaption></figure>.
- Do NOT replace with text or description.

The supplied HTML and images belong to the SAME PDF document.

TABLE IMAGES (CRITICAL — OVERRIDES IMAGE PRESERVATION)
This rule overrides the general image preservation rule.
If the attached image visually contains a TABLE (a grid with rows and columns):

STEP 1 — Remove the <img> tag. Do NOT keep it. Do NOT wrap it in <figure>.

STEP 2 — Extract EVERYTHING visible in the image, top to bottom:

A) Text ABOVE the table (headings, numbered titles, captions):
   - Bold heading/title  -> <h4 class="extracted-heading">...</h4>
   - Italic/smaller line -> <p class="extracted-subheading">...</p>
   Do NOT duplicate text that already exists in the surrounding HTML.

B) The table itself:
   <div class="table-responsive">
     <table>
       <thead><tr><th>...</th></tr></thead>
       <tbody><tr><td>...</td></tr></tbody>
     </table>
   </div>
   - Preserve every cell's content exactly.
   - Use <th> in <thead> for header rows.
   - Use colspan / rowspan for merged cells.
   - Preserve bullet points inside cells as <ul><li>.
   - Do not summarize or abbreviate anything.

C) Text BELOW the table:
   <p class="extracted-note">...</p>

STEP 3 — Wrap A + B + C in ONE outer div:
<div class="extracted-table-block">
  ...headings (A)...
  <div class="table-responsive"><table>...</table></div>
  ...footnotes (C)...
</div>

Place the extracted-table-block exactly where the original <img> was in the document.
